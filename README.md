# Программирование на платформе .NET — Лабораторные работы

Консольное приложение на **C# (.NET 10.0)**, объединяющее 11 лабораторных работ по курсу «Программирование на платформе .NET» (ИМИ).

## Структура проекта

```
DotNet/
├── DotNet.sln              # Решение
├── DotNet.csproj           # Проект (net10.0, консоль)
├── Program.cs              # Главное меню: выбор лабораторной
├── Laba1/Tasks.cs          # Базовые конструкции C#
├── Laba2/Tasks.cs          # ООП: классы, наследование
├── Laba3/Tasks.cs          # Файлы, массивы, кодировки
├── Laba4/Tasks.cs          # Строки, матрицы, константы, перегрузка
├── Laba5/Tasks.cs          # Делегаты и события
├── Laba6/Tasks.cs          # ADO.NET, DataSet, DataTable
├── Laba7/Tasks.cs          # LINQ, лямбда-выражения
├── Laba8/Tasks.cs          # ORM, Entity Framework, JSON
├── Laba9/Tasks.cs          # GDI+, графика, System.Drawing
├── Laba10/Tasks.cs         # Обработка изображений, фильтры
├── Laba11/Tasks.cs         # XML: чтение, запись, редактирование
├── screenshots/            # Скриншоты запуска каждой лабораторной
└── Программирование_на_платформе_NET/  # Лекции и задания
```

## Запуск

```bash
dotnet run
```

Появится интерактивное меню — выберите номер лабораторной (1–11), затем конкретное задание.

## Состав лабораторных работ

### Laba 1 — Базовые конструкции C#
| № | Задание |
|---|---------|
| 1 | Линейное уравнение `ax + b = 0` |
| 2 | Максимум из двух чисел |
| 3 | Склонение слова «гриб» |
| 4 | Круг и квадрат (вписывание) |
| 5 | Сравнение скоростей км/ч и м/с |
| 6 | Определение возраста по дате рождения |
| 7 | Приветствие по фамилии |
| 8 | Расписание на неделю |

### Laba 2 — ООП: классы, наследование
- Абстрактный класс `Car` (поля, методы `Start`, `Stop`, `Speedup`, `SlowDown`)
- Класс `Radio` (композиция)
- Классы-наследники: `Toyota`, `Ferrari`, `Bugatti`
- Полиморфизм: переопределение `Speedup` в `Toyota`
- Интерактивная демонстрация: создание автомобилей, ускорение, замедление

### Laba 3 — Файлы, массивы, кодировки
| № | Задание |
|---|---------|
| 1 | Зубчатый массив случайных строк (буквы a–z, A–Z), запись в файл |
| 2 | Подсчёт символов 's'/'S' в каждой строке из файла |
| 3 | Перекодировка файла CP866 → UTF-8 |
| 4 | Замена слова «объект» → «класс», подсчёт слов |
| 5 | Вывод содержимого директории (папки и файлы) |

### Laba 4 — Строки, матрицы, константы, перегрузка
| № | Задание |
|---|---------|
| 1 | Замена каждого второго вхождения слова (реверс) |
| 2 | Квадратная матрица, поиск максимумов строк |
| 3 | Невыровненная матрица букв a–k, замена a→e, транспонирование |
| 4 | Константы (`const`) |
| 5 | Статические методы и переменные |
| 6 | Пользовательский индексатор (`this[int]`) |
| 7 | Перегрузка методов |
| 8 | Перегрузка операторов (`Vector2D`) |

### Laba 5 — Делегаты и события
| № | Задание |
|---|---------|
| 1 | Базовые делегаты |
| 2 | Многоадресные делегаты (+=, -=) |
| 3 | События: `TemperatureSensor` с подписчиками `Monitor`, `Logger` |
| 4 | Встроенные делегаты: `Action<T>`, `Func<T,R>`, `Predicate<T>` |
| 5 | Асинхронный вызов через делегат (`BeginInvoke`/`EndInvoke`) |

### Laba 6 — ADO.NET
| № | Задание |
|---|---------|
| 1 | `DataSet` и `DataTable` (отсоединённый режим), `DataView` |
| 2 | Имитация работы с PostgreSQL через Npgsql (строка подключения, адаптер) |
| 3 | Сохранение/загрузка `DataSet` в XML |
| 4 | Отношения между таблицами (`DataRelation`) |

### Laba 7 — LINQ
| № | Задание |
|---|---------|
| 1 | Интегрированный синтаксис (`from...where...select`) |
| 2 | Лямбда-выражения и методы расширения (`Where`, `Select`, `Average`) |
| 3 | Группировка (`group by`, `GroupBy`) |
| 4 | Соединение коллекций (`join`, `GroupJoin`) |
| 5 | Комплексный запрос: топ-3 по стипендии |

### Laba 8 — ORM, Entity Framework, JSON
| № | Задание |
|---|---------|
| 1 | Контекст данных (аналог `DbContext`), классы-проекции таблиц, CRUD |
| 2 | JSON: сериализация / десериализация (`System.Text.Json`) |

### Laba 9 — GDI+ и графика
| № | Задание |
|---|---------|
| 1 | Основные типы `System.Drawing` (`Point`, `Rectangle`, `Color`, `Pen`) |
| 2 | Рисование на `Graphics` (линии, прямоугольники, эллипсы, текст, полигоны) |
| 3 | Работа с цветом (`FromArgb`, HSB-преобразования) |
| 4 | Перья и кисти (`DashStyle`, `HatchBrush`, `LineCap`) |
| 5 | Вывод изображений (`SizeMode`, `Bitmap.Save`) |

> **Примечание:** полноценный рендеринг через System.Drawing.Common доступен только на Windows. На macOS/Linux демонстрируется API без создания файлов изображений.

### Laba 10 — Обработка изображений
| № | Задание |
|---|---------|
| 1 | Информация об изображении (размер, формат, разрешение) |
| 2 | Фильтры: grayscale, invert, brightness, contrast, box blur, sepia |
| 3 | Гауссово размытие, повышение резкости (sharpen), выделение границ (Sobel) |
| 4 | Сводная таблица фильтров (аналог Accord.NET) |

### Laba 11 — XML
| № | Задание |
|---|---------|
| 1 | Чтение и запись XML через `XmlDocument` (DOM) |
| 2 | Редактирование XML (добавление/изменение узлов) |
| 3 | LINQ to XML (`XDocument`, `XElement`) |
| 4 | Потоковое чтение/запись через `XmlReader`/`XmlWriter` (SAX-подход) |
| 5 | Структура XML, DTD, XSLT, SAX vs DOM, XAPI |

## Сборка

```bash
dotnet build
```

## Зависимости

- [.NET SDK 10.0](https://dotnet.microsoft.com/)
- `System.Drawing.Common` (NuGet) — для Laba 9 и 10
- `mono-libgdiplus` (macOS: `brew install mono-libgdiplus`) — опционально для графики
